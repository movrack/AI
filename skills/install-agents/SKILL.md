# Install the agents of this repository

The agents in `agents/*.md` use neutral tool names, so they cannot simply be copied or symlinked. The bundled
script `scripts/sync_agents.py` (Python 3, standard library only) converts them to the format of each assistant.

## When to use
The user asks to install, set up, update or check these agents in one or more assistants.

## Steps
1. **Find the repository.** The script lives in `skills/install-agents/scripts/` and reads `agents/` of the same
   repository by default. If this skill was copied elsewhere, locate the clone (ask the user) and pass
   `--source <path-to>/agents`.
2. **Detect the assistants.** Check which of `~/.claude`, `~/.codex`, `~/.gemini`, `~/.copilot` exist. Ask the user
   which to install (default: all detected) and the scope:
   - user-level (all projects, the default), or
   - project-level in a given repository (`--scope project --project <path>`; writes `.claude/agents/` and
     `.github/agents/`, plus `.gemini/agents/` and `.codex/agents/`).
   Optionally ask whether to install only some agents (`--only name1,name2`).
3. **Dry run first.** Run, for example:
   `python3 skills/install-agents/scripts/sync_agents.py --assistants claude,copilot --dry-run`
   Show the plan (one line per file: created / updated / unchanged / backup), ask for confirmation, then run the
   same command without `--dry-run`. Report the summary line; any error makes the exit code non-zero.
4. **Restart.** Tell the user to restart the assistant (or open a new session) so it loads the new agents.
5. **Update and check.** After a `git pull`, re-run the same command: unchanged files stay untouched, changed ones
   are rewritten. A dry run at any time shows whether anything is out of date (everything "unchanged" means up to date).

## Safety rules
- Never delete anything, in the repository or in the assistants' folders.
- Never edit a generated file by hand: every output starts with a "generated by sync_agents.py" line and is
  overwritten at the next run. Change the source in `agents/` and re-run instead.
- A file in the target folder that this script did not generate is copied to
  `~/.config/ai-agents/_backup/<timestamp>/` before being replaced (also a symlink: the link is replaced, the
  backup keeps its content and target). Tell the user when a backup was made.
- Always do the dry run and get the user's confirmation before writing.
- The script is tested: `python3 -m unittest discover skills/install-agents/tests -v`.
